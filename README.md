# Contato · Elias Rodrigues

Página pessoal que reúne portfólio, redes profissionais e canais de contato em uma experiência responsiva, com temas claro e escuro.

**[Acesse o site →](https://eliasnrodrigues.github.io/contato/)**

## Objetivo

Oferecer um ponto único para conhecer meu trabalho e iniciar uma conversa sobre áudio ao vivo, produção musical ou projetos de dados e automação.

## Funcionalidades

- Layout adaptável a celulares e computadores.
- Alternância entre modo dia e noite, com a foto correspondente a cada tema.
- WhatsApp com mensagem inicial preenchida.
- Links para portfólio de áudio, Instagram, LinkedIn e GitHub.
- Janela de seleção de serviço para direcionar o contato.
- Controles com rótulos acessíveis, indicação de foco e respeito à preferência por movimento reduzido.

## Tecnologias

HTML, CSS e JavaScript, com hospedagem no GitHub Pages. O projeto não exige instalação de dependências nem etapa de compilação.

## Como executar

1. Clone o repositório:

   ```bash
   git clone https://github.com/eliasnrodrigues/contato.git
   ```

2. Abra a pasta `contato` no VS Code.
3. Abra `index.html` no navegador ou utilize um servidor local, como a extensão Live Server.

## Estrutura

| Arquivo/pasta | Responsabilidade |
| --- | --- |
| `index.html` | Conteúdo, links e estrutura da página |
| `Style.css` | Layout responsivo e estilos dos temas |
| `script.js` | Alternância do tema e controle da janela de serviços |
| `assets/` | Fotos e demais recursos visuais |

## Personalização

Os links e textos estão em `index.html`. As cores e os tamanhos ficam em `Style.css`. A lógica de troca das fotos está em `script.js`.

O site inicia no modo dia. A troca de tema vale para a página aberta; a preferência não é persistida após recarregar.

## Verificação manual

- Abrir a página em celular e computador.
- Alternar os temas e conferir a foto, o fundo e os textos.
- Abrir e fechar a janela de serviços, inclusive com a tecla Escape.
- Navegar pelos controles usando Tab.
- Conferir os destinos das redes sociais e os contatos do WhatsApp.

## Origem e créditos

O projeto começou a partir do **DevLinks**, material educacional da [Rocketseat](https://github.com/rocketseat-education). A versão atual adapta a apresentação, os estilos e os canais de contato ao portfólio de Elias Rodrigues.
